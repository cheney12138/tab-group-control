# 主题「sky」设计说明(蓝天颗粒 · 白线稿)

> 参考图:`蓝天 + 白云 + 白色手绘线稿 + 重胶片颗粒`(用户提供,2432×1018 sRGB)。
> 本篇是**开工前的设计交底**:先锁设计点与纪律,再动 `popup.html`。
> 契约见 `docs/adr/0003-theming-protocol.md`,开工清单见 `docs/theming.md`。

## 一、参考图核心设计点(逐像素取样,非凭印象)

取样脚本:`/tmp/analyze_theme.py`(Pillow,全图 247 万 px 统计)。

| # | 设计点 | 实测证据 | 在 UI 里的职责 |
|---|---|---|---|
| 1 | **双色纪律**:全图只有天蓝 + 云白两个色相,无第三色 | 天空区占 44%,云区约 10%(边缘过渡另外 ~20%);除蓝白外无其他色相像素 | 主题不得出现"第二个彩色面";所有彩色只以组色点/强调色小面积出现 |
| 2 | **天空是渐变,不是平涂** | 左上 `#395FB4` → 右下 `#688AD3`,中心 `#4268C1`;天空 p5–p95 = `#2B50A5`–`#4C71C6`,众数 `#4A6FC5` | 天空层(bg/顶栏)走 135° 渐变;深端不超过 `#2B50A5`,浅端不超过 `#688AD3` |
| 3 | **云白是冷白,不是中性白** | 云区 p5–p95 = `#B7C6D8`–`#EDEFFC`,均值 `#D2DAE8`;B 通道恒为最高(R211 G218 **B231**) | 所有"云层"表面用蓝调白(`#E7ECF8` 一带),禁用 `#FFF`/中性灰 |
| 4 | **重胶片颗粒是全图签名** | 平坦区局部亮度标准差 ≈ **16**(三处独立取样 16.07 / 16.20 / 16.48) | 主题最易识别的资产;天空带强颗粒,文字区只能极淡,否则毁可读性 |
| 5 | **纯白只属于线稿** | 全图近纯白(所有通道 >250)仅 272 px,全部是那幅手绘线稿 | `#FFFFFF` 是**线稿专用色**,云面/文字永不用纯白 |
| 6 | **线稿是 1–2px 手绘**,圆头、不规整 | 线宽细、曲率不完美、非工业矢量 | 装饰线/滑块/分隔线用"手绘感"细线,不用直线硬边 |
| 7 | **云缘是抖动/半调过渡**,不是硬边 | 天空→云的过渡横跨 ~20% 像素,亮度连续,边缘呈噪点 | 云层边界靠柔化/圆角,禁止 1px 硬描边切分 |
| 8 | **大留白,主体极小** | 画面 ~9:1 是天空留白,线稿只占中心一小块 | 主题气质 = 透气;不叠花纹、不加密度、不做"信息贴满" |

**气质一句话**:90 年代动画 OP 的蓝天 —— 明亮、透气、怀旧、颗粒感。

## 二、关键矛盾与化解(必须先说清)

参考图是一张**没有文字的海报**;弹窗是一个**高密度可读列表**。直接把整屏刷成天蓝 + 重颗粒 = 文字全废(这正是 y2k 第一版"太重"的同型翻车)。所以本主题不做"整屏天空",而做**天空在上、云海在下**的分层结构 —— 这恰好复刻参考图的构图(上方/外围天空,下方云堆):

```
┌─────────────────────────────┐
│  天空层 SKY  (蓝渐变 + 强颗粒)  │ ← 搜索盘 + 视图 Tab;白线稿装饰在此层
├─────────────────────────────┤
│  云层 CLOUD  (蓝调冷白 + 极淡颗粒)│ ← 分组/标签行/卡片/设置面板;深蓝墨文字
│                               │
└─────────────────────────────┘
```

- **天空层**承载全部"气质":渐变、颗粒、纯白线稿、白色图标/文字。
- **云层**承载全部"信息":冷白面、深蓝墨字、极淡颗粒,保证可读性。
- 天空带与云的交界**不允许任何形状/硬边**: 天空整体放在 `.search-plate::before`,再用一块「上实下虚 + feTurbulence 破形」的 mask 把它自己的底部溶掉 —— 蓝色自己化开, 没有“盖”上去的第二层。

## 三、设计纪律(改这个主题前先读,类比 y2k 取色纪律)

1. **双色纪律**:只有天蓝与云白两个色相。禁止出现第二个彩色面;彩色只准以组色点 / 强调色 / 状态标签的小面积出现。
2. **天空带明度纪律**:`#2B50A5`(深端)~ `#688AD3`(浅端)。更深会读成「夜晚/终端蓝」,更浅会与云白撞失去层次。
3. **颗粒纪律**:颗粒是本主题签名,噪点作为 `.search-plate::before` 的首层背景用 `background-blend-mode: overlay` 叠在天色上(强度由 `feComponentTransfer` 的 slope 标定, 不另加 opacity);文字所在云面的全局 `body::before` 只能是 multiply `opacity 0.16`。禁止用 `filter: blur()` / 发光替代颗粒。
4. **云白纪律**:云面一律蓝调白(`#E7ECF8` 一带),B 通道最高;禁中性白、禁纯白。
5. **纯白纪律**:`#FFFFFF` 只给线稿与天空层上的文字/图标;云面与正文禁用纯白。
6. **线稿纪律**:装饰线 1–2px、圆头(`stroke-linecap: round`)、允许曲率不完美;禁直线硬边与工业等宽硬角。
7. **留白纪律**:不叠纹理图案(区别于 ink 的宣纸点阵、y2k 的织纹)、不加边框盒、不给云面加投影,层级只用极淡的蓝调阴影。
8. **反简笔纪律**:云/光等自然元素一律"大尺度 + 不对称 + 模糊化开";禁止任何等距重复的几何小图形(小扇贝、小圆点边框、等宽波浪)当装饰 —— 那是简笔画,不是天气。云只准出现在天空带,不准下到列表。
9. **自溶纪律(最重要的过渡规则)**:天空与云的交界只准由**天空层自己 mask 溶解**,禁止"先铺蓝、再在上面盖一层白云形状" —— 后者不管形状多柔都会留下那道云团的边(用户眼里的"底线")。截面灰度曲线只要不是单调下降(出现平台/拐点),就是盖子不是溶解。

## 四、Token 落地映射(初稿)

| Token 组 | 取值方向 | 备注 |
|---|---|---|
| `--bg` | `#E4EAF7`(云层底) | 页面/列表/设置面板都是云;**天空不在 `--bg`,由顶栏资产局部承载** |
| `--surface` / `--pop-bg` | `#F2F5FC`(最亮云面) | 搜索框、卡片、弹层 |
| `--plate-bg` | `#3E64B9`(天空中值) | 契约必赋(实际由 `.search-plate` 渐变资产接管) |
| `--search-bg` / `--search-bg-focus` | `#F2F5FC` / `#F8FAFE` | 搜索框是云,不随天空变蓝 |
| `--text` | `#16224A`(云层深蓝墨) | 深端取自天空最深值再压暗,保证白底对比 |
| `--text-2` / `--text-3` | `#46538A` / `#7C89B4` | |
| `--accent` / `--accent-hi` | `#3D63BE` / `#2E4FA6`(参考图天空蓝) | 强调色 = 天空本色 |
| `--hairline` | `rgba(31, 52, 110, 0.12)` | 云层细线(手绘感由资产另做) |
| `--shadow-pop` / `--push-shadow` | 蓝调极淡柔影,零硬投影 | 云缘柔化 |
| `--r-*` | 比 linear 更圆(`--r-xs:8` … `--r-lg:18`) | 云朵语言 |
| `--tag-*` | 五态压进天空色域的低饱和档 | 与双色纪律一致 |

**5 个 accent 变体**:按「一天里的天色」走 —— `blue`=正午天蓝、`cyan`=清晨、`green`=雨后、`orange`=黄昏、`rose`=晚霞。全部低饱和,确保仍在蓝白世界里(沿用 ink 把 5 变体收敛为矿物色的做法)。

**9 色组色映射**:新增 `SKY_GROUP_COLORS`,`src/core/colors.js`,整体降饱和、偏冷,落在云天世界里。

## 五、主题资产清单(须块级注释 + 登记 `docs/theming.md`)

| 资产 | 位置 | 为什么需要动骨架 |
|---|---|---|
| 天空顶栏带 | `.search-plate` 渐变 + `.view-tab` 反白 | 顶栏要读成"天空",文字色须在天空层局部反白;这是与另四主题的骨架级分野 |
| 胶片颗粒 | `.search-plate::before` + `body::before`(feTurbulence) | 颗粒是签名资产;ink 已有 `body::before` 纹理先例 |
| 天空自溶(色层 mask) | `.search-plate` 透明底+余量 / `::before` 自身 mask | 只有独立元素能单独上 mask(直接 mask 容器会把搜索框/Tab 一起淡掉);天空要在**零分割线**下溶进云里 |
| 手绘云缘分隔线 | `.group-header::before` | linear 是两端渐隐直线,本主题是 2px 圆头手绘曲线(绝对定位,不动布局) |
| 白线稿滑块 | `.view-tabs .tab-slider`(仅此一处) | 天空层上唯一可见的纯白线稿装饰;设置面板的滑块在云上,保持强调色 |
| 云朵圆角 | `--r-*` 覆盖 | 云的语言,度量基座允许主题覆盖(同 herdr 方角先例) |

**颗粒/自溶落地参数(实测标定)**:噪点用 `feTurbulence` + `feColorMatrix` 转灰并把 alpha 强制为 1,
再用 `feComponentTransfer` `linear(0.98, -0.22)` 把亮偏的均值拉回灰 0.5 —— overlay 对灰 0.5 是恒等变换,
于是**均值不变、只加方差**(不校正就会把蓝天冲淡)。噪点直接作为 `.search-plate::before` 的首层背景、
`background-blend-mode: overlay` 叠在天色上(设了 `mix-blend-mode`/`opacity` 就变成两套混合, 不好标定)。
天空带实测 std≈12(参考图≈16);全局 `body::before` multiply `opacity 0.16`(云面实测 std≈2.3,
云底亮度 231→220, 正好落在参考图云区均值 220 上)。溶解 mask(`--sky-dissolve`)的湍流: `baseFrequency='0.010 0.09'`
(横向低、纵向高 = 边界横向起伏更缓)、`numOctaves=2`、`scale=20`(scale>30 会烂成大块斑)。
**mask 的 rect 必须外扩到 viewBox 之外**(`x/y=-60`、`width/height` 超出): 否则位移会把 rect 的四条边全抖出缺口,
顶部/左右漏出容器底色;可视区四边必须落在 rect 内部, 只有底部边界参与破形。透明端(viewBox `y=140`)还要
比元素底边(160)高出 ≥ 位移量(20), 否则被顶上来的蓝会在底边被硬裁成直线。`--sky-grain` 为 160px 可平铺 tile。
