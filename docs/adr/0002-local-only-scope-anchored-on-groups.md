# 纯本机、无账号,所有功能锚定「分组」场景

本插件是单机功能性工具,不是系统。两条边界在此写死,之后所有"要不要加 X"先过这两关:

1. **不引入云端与账号**。分组规则、归档卡、用户偏好全部存 storage.local,换机/卸载即焚。同步意味着账号、冲突、隐私处理,复杂度与这个插件的身位完全不成比例。
2. **功能只锚定「分组」场景,不发散成通用标签管理器**。未分组散标签视为临时状态,不可归档、不被管理——用户想要管理能力,先给这批标签一个身份(组名+色)。这个门槛是故意的:它给"临时看看"和"正式工作"之间留了产品压力,也保住了插件的概念边界。

反例记录:曾考虑"未分组区也可归档",被否——未分组本身就是用户没有管理意图的信号。
