Three Pillars

三大支柱,一个不少

搜索切换是入口,自动分组是秩序,归档收纳是喘息空间。三者咬合,才撑得起几百个标签页的日常。

01

搜索切换

⌘E 唤起,输入即搜。标题、全拼、首字母、组名、域名、URL 五路分层匹配,命中字符高亮。

  • 全量拼音引擎:20,924 汉字码点索引,零依赖,「dingdan」命中「订单管理」
  • 命令模式:/b 搜书签、/h 搜历史、/r 找回最近关闭
  • 组名精确置顶,重复 URL 自动折叠计数
  • 三个视图:分组 / 最近使用 / 当前窗口,Tab 键循环
02

自动分组

内置域名规则引擎,新标签和页内跳转都自动归组。标签栏从此不用手动整理。

  • 域名规则:精确主机(含 www 别名),*.域名 通配显式声明,最长规则优先
  • 路径细分:同域多项目(个人/公司/org)按路径前缀各自进组
  • Others 兜底:不命中任何规则的标签自动入兜底组
  • 公共后缀 / localhost / IP 永不误伤,可完全替代 Tabbiy
03

归档收纳

阶段性不用的分组整组归档:拍快照、关标签、收进仓库。标签栏瞬间清爽。

  • 一键归档:组名 + 颜色 + 标签 URL 清单整体封存
  • 随时还原:在当前窗口全新加载,归回原组名的组
  • ⌘Z 抢救层:6 秒内的误关连分组一起还原
  • 一次性 stash 语义,纯本机存储,卸载即焚

Search Engine

中文场景,拼音是刚需

内置 20,924 个汉字的 Unicode 码点索引表,全拼、首字母、混合输入全部命中。不需要切换输入法,想到什么打什么。

  • 五路分层匹配:标题 > 拼音 > 组名 > 域名 > 完整 URL,精确子串优先于模糊匹配

  • 找回分层:⌘Z 管 6 秒抢救、/r 管关闭现场、/h 管浏览足迹,各管一段不重叠

Rule Engine

分组规则,声明一次永久生效

给每个分组绑定一组域名,之后新开的标签、页内的跳转全部自动归组。建组前先复用同名组,永远不会堆出重复组。

  • 通配显式声明:默认只精确匹配所写主机;写 *.bilibili.com 才含子域
  • 路径细分:github.com/cheney12138 按「主机+路径前缀」归组,同域多项目各自进组
  • 安全边界:github.io 等公共后缀、localhost、IP 永远只精确匹配,不误伤别人的站点
  • 规则编辑器:chip 式编辑、脏点提示、保存即生效,支持导入/导出 JSON

Batch Ops

右键一下,批量收场

  • 关闭本组其余标签 (n) / 关闭此标签下方 (n) / 关闭整组 (n)
  • 归档「组名」分组:关闭与归档语义分离,一个入口各就其位
  • 分组编辑同菜单直达:新建分组 / 改名改色 / 移出 / 解散
  • 6 秒内 ⌘Z 整批救回:静默开回原窗口、原位置、原分组,不抢焦点

  • 行内控制:播放/暂停、静音、画中画三个按钮浮在媒体行上

Engineering

本地优先,工程洁癖

隐私安全

纯本地,零网络请求

不登录账号、不同步、不上报。只用 storage.local 与 downloads 两个本地 API。你的标签数据永远不会离开这台机器。

性能

即点即开,零框架

原生 JavaScript + DOM,无框架无依赖,Manifest V3。content script 心跳保活 worker + 标签快照预热,弹窗打开延迟低于一次眨眼。

数据安全

配置自动备份

规则与开关变化时自动落一份 JSON 到下载目录,内容没变一个字节都不写。重装、换电脑,一键从备份恢复。装了下载管理器也照样对。
